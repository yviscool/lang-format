# Code of Conduct

## Our Standard

This project expects respectful, professional, and constructive collaboration.

- Be direct, but not hostile.
- Focus feedback on behavior, code, and decisions.
- Assume good intent, but document concrete problems clearly.
- Avoid harassment, discrimination, personal attacks, and disruptive behavior.

## Scope

This applies to issues, pull requests, discussions, and other project spaces.

## Enforcement

Project maintainers may remove content, lock threads, or restrict participation when behavior harms the project or its contributors.
